# Mon_cantine-
MoKantinn - Portail de la cantine universitaire Développer une plateforme web pour la cantine de l'UdM permettant aux étudiants  de consulter le menu du jour, les prix et la disponibilité, de laisser des avis et éventuellement de pré-commander (menus, horaires d'affluence, notation des plats,  gestion côté personnel).
